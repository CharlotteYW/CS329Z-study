# CS329Z: Engineering AI Agents — Self-Study Workspace

A self-paced learning workspace aligned with [Stanford CS329Z, Fall 2026](https://cs329z.stanford.edu/). The goal is to independently build and evaluate reliable agent systems, with a strong emphasis on inference, backend engineering, and production tradeoffs.

## Start here

Start with the [current study plan](lectures/week-01-plan.md) and use [progress](PROGRESS.md) to resume. The [roadmap](ROADMAP.md) maps course topics to engineering decisions; the [verified resource index](resources/course-materials.md) is available for reference.

The pace is **3–4 hours per week**. Follow the lecture videos, write brief notes, and use each week's `references.md` for selected readings and comparisons. Draw examples from the course materials and documented open source projects. Apply the material in the official assignments and a project.

## Working agreements

Repository content is English; conversation may be Chinese or English. The learner owns exercise implementations and explanations. AI assistance supports reasoning, debugging, and critique. Course project reports must be learner-authored under the [course AI-use policy](https://cs329z.stanford.edu/logistics).

Use Python and deterministic tests before model-dependent experiments. No environment installation or API key is needed for the first session. Local and hosted model choices will be compared when a task requires them.

Official course materials, mentor-designed requirements, and optional enrichment are labeled. This workspace does not imply Stanford enrollment or course credit. Restricted content is not mirrored or bypassed.
